# 💻 CodeCraft Studio - Multi-Page Agency Website

A modern, responsive, multi-page frontend web prototype built to showcase agency services, custom layout grids, and interactive form handling.

## 📌 Features
- **Multi-Page Navigation:** Seamless routing between Home (`index.html`), Services (`services.html`), and Contact (`contact.html`).
- **Responsive Layout:** Powered by Bootstrap 5 grid system and modular CSS for mobile and desktop screens.
- **Interactive UI:** Dynamic JavaScript submission alert and input reset on the contact form.
- **Structured Data:** Clear pricing/estimates table and feature cards.

## 🛠️ Tech Stack
- **HTML5** (Semantic Structure)
- **CSS3** (Custom Styling & Hover Animations)
- **Bootstrap 5** (Grid & UI Components)
- **JavaScript** (DOM Manipulation & Form Events)
